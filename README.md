# RXPGuides - Mac's Custom Guide

Night Elf leveling route for WoW Forever, built on [RXPGuides](https://github.com/RestedXP/RXPGuides). It is adapted from a 5-man route to work for any group size from 1 to 5.

## Route overview

| Levels | Zone(s) |
|---|---|
| 1-7 | Shadowglen / Teldrassil, Elwynn, Westfall |
| 7-11 | Elwynn |
| 11-12| Loch Modan|
| 12-15 | Darkshore |
| 15-16 | Westfall / Redridge |
| 16-18 | Hall of Thanes |
| 18-20 | Darkshore |
| 21-23 | Darkshore / Ashenvale |
| 23-24 | Blackfathom Deeps |
| 23-25 | Redridge / Duskwood |

## Files

- `Forever Duo 1-10.lua`: starting zone through level 11
- `Forever Duo 10-20.lua`: Darkshore, Westfall/Redridge, Hall of Thanes, Loch Modan, plus an `Inbox` guide of leftover steps
- `Forever Duo 20-30.lua`: draft
